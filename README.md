# 🚀 Flask Portfolio Website

A dynamic portfolio website built with **Python and Flask** to showcase DevOps and Python projects. This project demonstrates full-stack development skills, backend routing, JSON integration, and DevOps tooling.

---

## 📌 Features

- Developed using **Flask** and **Jinja2** templates
- Project data loaded dynamically from a **JSON file**
- Functional **contact form** for user messages
- Clean, responsive UI with **HTML and CSS**
- Integrated with **Git** and hosted on **GitHub**
- *(Optional)* Docker support for containerized deployment

---

## 🔧 Tech Stack

- **Language:** Python  
- **Backend Framework:** Flask  
- **Frontend:** HTML, CSS  
- **Templating:** Jinja2  
- **Storage:** JSON  
- **Version Control:** Git, GitHub  
- **(Optional)**: Docker
